## Things that WILL help you
- Remember [YAML FUCKING SUCKS](https://github.com/cblp/yaml-sucks) (didn't know people actually had the same feeling as I ts is bad as hell) if you have passwords with special characters like $ and # ONG DON'T its just a headache
- Look close at the [nginx.conf](./nginx.conf) the trailing / for example is very important...
- [testmatrix](https://codeberg.org/spaetz/testmatrix/) based giga chad tool to help debug your homeserver helped 
- My matrix bridges are all From [maunium](https://maunium.net) very based bridges sometimes bit of a hastle to setup
- DON'T use an @ in the TUWUNEL_SMTP__SENDER variable before the <email@adress.yo> it just won't start
